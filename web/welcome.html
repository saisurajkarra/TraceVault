tracevault

Welcome — let's build your knowledge base.

tracevault turns your real work — any folder, a git repo, your Claude Code sessions — into a private lakehouse you can search and explore as a graph. Point it at a first source to begin. Everything stays on your laptop; nothing is uploaded.

Step 1 · Add a source
Type or paste a full path. A folder ingests every file (code, docs, images — all made searchable). A git repo also ingests its commit history.
    Step 2 · Build it
    Add at least one source above.
    First run downloads a small local model the first time, then reads, captions images, and embeds every file. Larger sources take longer — you can watch it climb.
    ● Local-first & private · real MinIO + Apache Iceberg under the hood · once it's built you'll land on your knowledge graph automatically.
